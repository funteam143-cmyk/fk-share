# FK Face AI

Android starter project with a WebView interface, phone media picker, and five planned AI tools: Photo Face Swap, Video Face Swap, Motion Control, Character Swap, and AI Talking Photo.

**Current status:** The Android shell and upload UI are implemented. AI inference is NOT connected yet. No real face swap is generated in this starter. Free hosted GPU runtimes have usage limits and are not guaranteed to stay online. The plan is to connect open-source inference with a genuinely free option where available; no paid API or server is configured.

Use only photos/videos you own or have permission to edit. Do not create deceptive or non-consensual impersonations.
